## 👋 Quiero decirte algo

Soy estudiante de **Ingeniería de Sistemas** en la **UNTELS** y estoy justo en el punto donde la programación y el testing se combinan.

Me presento como **QA primero, desarrollador después**. No puedo escribir código y listo: necesito que sea correcto, rápido y confiable. Para lograrlo soy tester —crítico, meticuloso, directo— y a la vez programador —creativo, práctico, resolutivo. Cada bug no lo veo como un problema, sino como la oportunidad de entregar algo mejor.

Las bases son claras: uso la metodología **ISTQB** para decidir qué y cómo probar, ordeno el proceso completo con el **STLC / SDLC**, y trabajo en equipo con **Agile / Scrum** de verdad, no solo de nombre.

---

## 🎯 Cómo encaro el testing

- Recorro el **ciclo de vida completo** de una prueba: requerimientos → diseño → ejecución → reporte → mejora.
- Diseño casos usando técnicas probadas: **análisis de valores límite**, **partición de equivalencia** y **tablas de decisión**.
- Automatizo lo repetitivo y dejo espacio para lo que necesita ojo crítico y contexto.
- Convierto cada hallazgo en **retroalimentación útil para quien desarrolla**, nunca en un reclamo.
