## ✦ Un poco sobre mí

Soy estudiante de **Ingeniería de Sistemas** en la **UNTELS** y vivo en la intersección entre **escribir código** y **demostrar que funciona**: un día diseño una API, y al siguiente la pongo a prueba con casos que ningún usuario pensó en tocar.

Mi trabajo está guiado por **ISTQB**, ordenado por el **STLC / SDLC** y hecho para equipos **Agile / Scrum**. No creo en el "aproximadamente funciona": creo en **pruebas, evidencia y software que aguanta producción**.

| 📈 | Reporto hallazgos útiles para el equipo, nunca reclamos |
| 🔁 | Integro pruebas en **CI/CD** para cuidar cada deploy |
